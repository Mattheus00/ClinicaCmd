# Saúde em Equilíbrio

Landing page da Clínica Integrativa Saúde em Equilíbrio, feita em HTML, CSS e JavaScript.

A página referencia as imagens e os vídeos em `public/media`. Essa pasta deve estar disponível no mesmo diretório do HTML para reproduzir a versão completa.

Para visualizar a página localmente, execute `python -m http.server 8000` na raiz do projeto e acesse `http://localhost:8000/`.
